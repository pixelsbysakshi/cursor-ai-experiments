# Sakshi Parashar - UX Designer Portfolio

A modern, responsive portfolio website showcasing UX design work and expertise. Built with Material Design 3 principles, featuring a clean interface with dark/light mode toggle.

## 🌟 Features

- **Responsive Design** - Works seamlessly on all devices
- **Dark/Light Mode** - Theme toggle with preference persistence
- **Modern UX** - Material Design 3 inspired interface
- **Smooth Animations** - Subtle micro-interactions for better UX
- **SEO Optimized** - Proper meta tags and semantic markup
- **Contact Form** - Functional contact form with validation
- **Social Integration** - Links to professional profiles

## 🚀 Deployment Options

### Option 1: GitHub Pages
1. Push code to GitHub repository
2. Go to repository Settings > Pages
3. Select source branch (main)
4. Your site will be live at `https://yourusername.github.io/repository-name`

### Option 2: Netlify
1. Connect your GitHub repo to Netlify
2. Deploy settings are auto-configured via `netlify.toml`
3. Get instant SSL and global CDN

### Option 3: Vercel
1. Connect GitHub repo to Vercel
2. Deploy settings are configured via `vercel.json`
3. Get edge functions and analytics

### Option 4: Local Development
```bash
# Install dependencies
npm install

# Start local server
npm start

# Opens browser at http://localhost:3000
```

## 🎨 Customization

### Colors (CSS Custom Properties)
- `--m3-primary`: Main brand color
- `--m3-background`: Page background
- `--m3-surface`: Card backgrounds
- `--m3-on-surface`: Text color

### Content Updates
- Update personal information in `index.html`
- Replace placeholder images in `Assets/` folder
- Modify project details in the portfolio section
- Update social media links
