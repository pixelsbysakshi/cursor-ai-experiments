# Portfolio Website - Folder Structure

## 📁 Project Organization

Your portfolio website has been organized into a professional folder structure:

```
portfolio-website/
├── index.html              # Main HTML file (entry point)
├── README.md               # Project documentation
├── FOLDER_STRUCTURE.md     # This file
├── css/
│   └── styles.css          # All CSS styles and animations
├── js/
│   └── script.js           # All JavaScript functionality
├── images/                 # For portfolio images and photos
├── assets/                 # For icons, fonts, and other assets
└── projects/              # For individual project assets

```

## 🔧 Updated File References

The following changes were made to organize the code:

### ✅ HTML Updates (index.html)
- **CSS Reference**: Changed from `href="styles.css"` to `href="css/styles.css"`
- **JavaScript Reference**: Changed from `src="script.js"` to `src="js/script.js"`

### 📂 File Locations
- **Stylesheet**: `css/styles.css` (moved from root)
- **JavaScript**: `js/script.js` (moved from root)
- **Main Page**: `index.html` (remains in root)

## 🚀 How to Use

1. **Open the portfolio**: Open `index.html` in your browser
2. **Add images**: Place portfolio images in the `images/` folder
3. **Add project assets**: Store individual project files in `projects/` folder
4. **Additional assets**: Place icons, fonts, etc. in `assets/` folder

## 📝 Benefits of This Structure

- **Professional Organization**: Clean separation of concerns
- **Scalability**: Easy to add more CSS/JS files as the project grows
- **Maintainability**: Clear file locations for easy maintenance
- **Best Practices**: Follows industry standards for web development
- **Collaboration**: Makes it easier for teams to work together

## 🔄 Future Additions

When adding new content:
- **Images**: Add to `images/` folder and update paths in HTML
- **Additional CSS**: Create new files in `css/` folder
- **Additional JS**: Create new files in `js/` folder
