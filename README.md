## 🎯 Customization Guide

### Personal Information
Replace the placeholder content in `index.html`:

1. **Name and Branding:**
   - Update "Alex Chen" with your name
   - Change the title and meta description

2. **Contact Information:**
   - Email: `alex.chen.design@email.com`
   - Phone: `+1 (555) 123-4567`
   - Location: `San Francisco, CA`

3. **Social Media Links:**
   - LinkedIn, Dribbble, Behance, Twitter links in the contact section

### Portfolio Projects
Update the three featured projects in the portfolio section:

1. **Project Images:**
   - Replace the placeholder icons with actual project screenshots
   - Recommended size: 350px × 200px

2. **Project Details:**
   - Update titles, descriptions, and tags
   - Add links to your case studies or live projects

### Skills and Tools
Customize your expertise:

1. **Skill Categories:**
   - Modify the four main skill areas
   - Update descriptions to match your expertise

2. **Design Tools:**
   - Add or remove tools from the tools grid
   - Common tools: Figma, Sketch, Adobe XD, etc.

### Color Scheme
Modify colors in `styles.css` by updating CSS variables:

```css
:root {
    --primary-color: #667eea;      /* Main brand color */
    --secondary-color: #764ba2;    /* Secondary brand color */
    --accent-color: #f093fb;       /* Accent color */
    /* ... other colors */
}
```

### Adding Your Photo
Replace the user icon placeholder:

1. Add your professional photo to the project folder
2. Update the about section in `index.html`:
   ```html
   <div class="image-placeholder">
       <img src="your-photo.jpg" alt="Your Name" />
   </div>
   ```

## 🚀 Going Live

### Option 1: GitHub Pages
1. Create a GitHub repository
2. Upload files to the repository
3. Enable GitHub Pages in repository settings
4. Your site will be live at `username.github.io/repository-name`

### Option 2: Netlify
1. Drag and drop your folder to [Netlify](https://netlify.com)
2. Get an instant live URL
3. Optional: Connect to GitHub for automatic deployments

### Option 3: Traditional Hosting
- Upload files to any web hosting provider
- Ensure `index.html` is in the root directory
